How to Use the System

This portal helps students and staff report and recover lost items within the university quickly and securely.

Report Lost Item

If you have lost an item, use the Report Lost page to submit its details.

Provide a clear description such as the item name, color, where you last saw it, and any unique features. This increases the chances of recovery.

Report Found Item

If you find an item that does not belong to you, submit it through the Report Found page.

Your honesty helps reunite owners with their belongings. Once submitted, the admin reviews and contacts the rightful owner.

Search Items

The Search page allows users to browse through reported items.

If you lost something, always search first before reporting. Many items are often found and uploaded by other users.

Additional Tips

• Always use accurate information when submitting reports.

• Avoid submitting false reports.

• The admin will contact you only if a match is found.

• This system is meant to support honesty, responsibility, and community care.
